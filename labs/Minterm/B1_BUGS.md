## วิธีกรอก (อ่านก่อนเริ่ม)

กรอกให้ครบ **ทั้ง 6 บั๊ก** · แต่ละบั๊กเขียน 3 อย่างด้วย **คำของตัวเอง** (จะถูกสุ่มถามใน oral)

| คอลัมน์ | ใส่อะไร | ตัวอย่างสิ่งที่เขียน *(บั๊กสมมติ)* |
|---|---|---|
| **ไฟล์ : บรรทัด** | ไฟล์ที่แก้ + เลขบรรทัด | `Foo.jsx : 12` |
| **สาเหตุ** | **ทำไม** มันทำงานผิด (ไม่ใช่แค่ "พิมพ์ผิด") | "ใส่วงเล็บท้ายชื่อฟังก์ชัน เลยถูกเรียกทันทีตอน render" |
| **แก้อย่างไร** | เปลี่ยน**จากอะไร**เป็น**อะไร** | "เอาวงเล็บออก จาก `onClick={fn()}` เป็น `onClick={fn}`" |

> เคล็ด: เลขบรรทัดดูได้จากแถบซ้ายใน VS Code หรือจากข้อความ error ใน Console (เช่น `RequestList.jsx:9`)

## ตัวอย่างรูปแบบการเขียน

> ⚠️ นี่คือ **บั๊กสมมติเพื่อสอนวิธีเขียน** — **ไม่ใช่** บั๊กจริงในข้อสอบ

| อาการ | ไฟล์ : บรรทัด | สาเหตุ | แก้อย่างไร |
|---|---|---|---|
| กดปุ่มไม่ได้ แต่พอโหลดหน้าเสร็จฟังก์ชันทำงานเองทันที | `Foo.jsx : 12` | เขียน `onClick={handleClick()}` มีวงเล็บ → JavaScript **เรียกฟังก์ชันทันที**ตอน render แล้วเอาค่าที่ return มาเป็น handler | เอาวงเล็บออก เป็น `onClick={handleClick}` (ส่งตัวฟังก์ชัน ไม่ใช่ผลลัพธ์) |

## บันทึกของฉัน — กรอกทั้ง 6 บั๊ก

| # | อาการ | ไฟล์ : บรรทัด | สาเหตุ (ทำไมผิด) | แก้อย่างไร |
|---|---|---|---|---|
| 1 | Console เตือนสีเหลืองเรื่องรายการ (list) ที่แผงสรุป | `SummaryPanel.jsx : 12` | `.map()` สร้าง `<article>` หลายตัวแต่ไม่มี `key` ให้แต่ละตัว React เลยแยกไม่ออกว่าตัวไหนคือตัวไหน | เติม `key={key}` ที่ `<article>` |
| 2 | ตัวเลข "เสร็จสิ้น" ในแผงสรุปไม่ตรงกับที่เห็นจริง | `DashboardPage.jsx : 50` | เงื่อนไขนับ completed เขียนเช็ค `status === 'in-progress'` ซ้ำกับบรรทัด inProgress (copy-paste แล้วลืมแก้) | แก้เป็น `request.status === 'completed'` |
| 3 | กดตัวกรองสถานะใด ๆ แล้วผลไม่เปลี่ยน | `DashboardPage.jsx : 55` | hardcode `'pending'` ตายตัว ไม่ได้อ่านค่าจาก state `statusFilter` เลย | เปลี่ยนเป็น `request.status === statusFilter` |
| 4 | เปลี่ยน URL `REQ-101` → `REQ-102` แล้วข้อมูลไม่เปลี่ยน | `RequestDetailPage.jsx : 28` | `useEffect` deps ว่าง `[]` เลยรันแค่ครั้งเดียวตอน mount ไม่รันซ้ำตอน `requestId` เปลี่ยน | แก้ deps เป็น `[requestId]` |
| 5 | กด "ลบ" แล้วการ์ดหาย แต่ตัวเลขในแผงสรุปไม่ลด | `DashboardPage.jsx : 51` | `useMemo` deps ว่าง `[]` เลยคำนวณ summary แค่ครั้งเดียว ไม่คำนวณใหม่ตอน `requests` เปลี่ยน | แก้ deps เป็น `[requests]` |
| 6 | กด "ลบ" แล้วหน้าพัง/ว่างเปล่า | `DashboardPage.jsx : 64` | เรียก `deleteRequest()` แบบไม่มี `await` ทั้งที่เป็น async function เลยได้ Promise มาเก็บใน state แทนที่จะเป็น array | เติม `await` หน้า `deleteRequest(requestId)` |
